2026-11-20 本地 1.1.5+8 更新：取消练习数量配置，范围内全量练习；题序、选项、位置和解析状态可跨退出恢复。现行说明见 `practice-continuity.md`，以下保留初始发布记录。

- 选择题从正式排程和每日额度候选中排除，基础卡、填空卡维持原算法。已有选择题历史记录和卡片字段保留，不清库、不重新导入。
- 牌组「选择题练习」、我的「错题列表」、收藏「收藏选择题练习」均支持顺序和随机，支持子章节范围。每轮 1–500 张，固定卡片快照，轮内不重复；顺序按 card.id 递增。
- 所有自由练习中的选择题提交进入 PracticeRepository.submitChoice，校验当前题目后事务判分。答错 upsert 独立 wrong_questions，答对删除；重新答错重新记入。预览、背卡、跳过、直接看答案均无判分副作用。
- 提交保存前禁用重复提交和下一题；失败保留选择重试。收藏独立，练习期间可收藏和编辑。
- 数据库 schema 1→2 仅新增 WrongQuestions，外键随卡片删除。备份严格验证 schema、数据及 manifest 一致性；支持恢复旧 schema 1 并自动迁移，schema 2 新备份需新版应用。
- 不增加网络、云同步、后台服务或 PDF 制卡功能。用户于 2026-11-16 授权将本版源码、APK 和指南上传 GitHub，公开版本号定为 v1.1.1。
