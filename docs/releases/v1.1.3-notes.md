# Lunar Memory v1.1.3

新增应用内字号调节，并包含选择题独立解析页。

- 「我的 → 字体大小」分别设置界面文字（80%–150%）和卡片阅读文字（80%–200%）。拖动实时预览，保存后生效；100% 跟随系统字号，支持恢复默认。
- 题干、选项、答案、解析和背卡正文使用阅读字号；两项倍率独立计算，设置随本地备份保存和恢复。
- 选择题提交后自动打开独立解析页，底部固定「返回题目」和「下一题」，最后一题为「完成本轮」。题目页原有下一张按钮保留，返回后保留选项与判分。
- 提前查看解析按未作答处理；重复查看不重新判分。选择题仍独立刷题，答错加入错题列表、答对自动移出；基础卡和填空卡的记忆排程保留。

附件包括 ARM64 APK（约 23.1 MB）及更新后的使用指南。适用于 Android 8.0 及以上；应用版本 `1.1.3`，内部版本码 `6`，沿用原有包名和签名，可覆盖安装，建议更新前导出本地备份。

本版为开发预览版，相关交互、备份和大字号布局检查通过，实际手机上的字号观感和覆盖安装仍待验收。无需服务器，核心功能完全离线。
