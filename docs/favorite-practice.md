# 收藏筛选与随机练习

进入「记录 → 查看收藏」，在「牌组范围」选择全部牌组或指定牌组。指定牌组默认包含所有层级的子章节，也可关闭「包含子章节」，只查看直接属于该牌组的收藏。同名章节用完整路径区分；切换牌组或章节开关会回到第一页，每页最多 30 张。

点击「收藏随机练习」，默认使用收藏页当前范围。练习从范围内的全部收藏抽取，不限列表当前页；可以调整是否包含子章节和练习张数（默认 20，1–500），数量不足时使用实际全部收藏。全部牌组模式涵盖所有章节，不单独显示子章节开关。空范围无法从列表开始练习，可以切换牌组或先收藏卡片。

练习页明确显示「仅练习收藏卡片」。沿用文字、图片、基础卡与填空卡的卡面显示，先回想，再点「显示答案」，随后「下一张」或「完成本轮」。本轮卡片不重复；不同填空编号仍是不同卡片。没有 FSRS 四项评分，不改变排程、额度、收藏、正式学习日志、首页已学数量、日历或连续天数。

每轮开始时固定 ID 列表；中途收藏状态变化不重排本轮，下一轮重新读取当前收藏。已删除或无法读取的卡片可以重试或跳过，跳过数量单独显示。若下一轮范围已空，会回到设置并提示。练习会话和收藏筛选仅保留在当前页面中，退出后不保证恢复。

收藏页原有单卡预览、取消收藏和撤销仍可用；从练习或预览返回时保留当前筛选与分页。所选牌组被删除后显示提示并保留失效选择，不自动扩大为全部牌组，需要重新选择范围。

## 手机验收

覆盖安装新版 APK，无需卸载或重新导入。检查父牌组包含/排除子章节、不同牌组切换、取消收藏与撤销；从第二页开始练习应能抽到第一页的收藏。练习前后核对首页与日历，正式统计应不增加。新功能自动验证覆盖 1220×2712／DPR3、375dp 小屏、2 倍字体、长章节名称、深色、横屏及减少动画；真实手机触感与图片表现仍需确认。

本轮不包含按标签、错误次数或最近错误日期筛选，也不包含收藏卡的专项正式评分。安装包仍使用原有测试签名，正式公开发布与多机兼容验证留待后续。
