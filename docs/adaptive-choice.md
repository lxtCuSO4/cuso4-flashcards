# 选择题一屏优先布局

日期：2026-11-19。开发版本：1.1.4+7。工作区：`D:/LunarMemory/.worktrees/cuso4-app`。

- 正式选择题练习、混合自由练习中的选择题、收藏／错题专项，以及直接打开收藏／错题选择题预览，统一使用紧凑 ChoicePracticeScaffold。
- 顶栏收藏、编辑和跳过菜单；正文减少重复说明和留白，选项使用字母徽标；固定底栏显示提交／查看解析，揭示答案后保留下一张或重新作答。
- AdaptiveChoiceViewport 按真实富文本布局高度测量。先收紧间距，再临时降低阅读倍率，最大缩小 25%，基准正文最低 16 逻辑像素（原字号更小时不再缩小）；仍超高时开启滚动条并保留全部内容。保存字号、系统缩放和点击区域大小保持独立。
- 图片按可用高度显示缩略图，加载时预留高度；点击打开可缩放图片，关闭返回，不误选选项。
- 临时重排不重建选项排列，不改变判分。提交、错题、收藏、编辑及慢速保存回调保持原语义。
- 预览使用独立解析页，但不进行持久化判分；解析页只有返回题目，不推进任何练习队列。基础卡、填空卡、背卡与编辑器布局保持原行为。
- 不改数据库结构或牌组格式，不新增依赖。本轮本地交付，实际手机观感待验收。

验证和安装包见 `docs/releases/2026-11-19-adaptive-choice.md`。

本地布局预览为 `build/previews/adaptive-choice-phone.png`，尺寸 1220×2712；使用宿主机字体供布局查看，字体未加入 APK，实际手机以自身系统字体为准。
