# 学习额度与 FSRS 设置增量

用户已认可实施每日新卡数、每日复习上限和 FSRS 期望保持率。沿用现有应用设计及 product-features plan Task 6，不增加每日目标、算法权重或各牌组单独覆盖设置。

## 行为约定

- 默认每个牌组每日新卡 20 张、复习 200 张、保持率 90%。新卡范围 0–9999，复习范围 0–99999，保持率为 70–99 的整数百分比。
- 额度按卡片所属牌组分别计算，父牌组不共享子牌组额度；学习中／重学中卡片不受两项额度限制。0 暂停对应类型。沿用已固定的学习日时区及午夜换日规则。
- 在“我的 → 学习设置”一次保存三项设置，存为 app_settings 单行 JSON；校验失败或写入失败不留下部分设置。缺失记录采用默认值，损坏记录明确报错。
- 每次进入学习先读取持久化设置，生成该轮不可变的仓储／FSRS 实例。加载失败不以默认设置开始。预览与评分使用同一实例；本轮重新载入及撤销保持一致。退出后重新进入应用新设置。
- 设置改变不重写已有卡片到期日、日志或学习状态；保持率在后续评分时参与计算。调低额度会考虑今天已用数量，撤销释放额度。
- 输入显示标签、范围和就近错误，保存有明显按键反馈、忙碌与成功／失败反馈；失败保留输入，未保存返回需确认。可滚动适配目标手机、大字、横屏和深色。

## 实施与验证

1. 添加类型化学习设置及持久化仓储，验证默认、重开恢复、边界、损坏及原子失败。
2. 接入会话设置快照，验证持久化额度、学习卡放行、换日与撤销，以及保持率预览／评分一致、旧到期日不改。
3. 添加设置页和入口，集中检查保存、失败保留输入、退出确认、目标尺寸／大字／深色／横屏。
4. 集中运行设置、学习和应用相关检查，静态分析；离线构建 ARM64 release，核对包身份／签名／代码哈希，保留旧 APK。
5. 更新进度并提交工程改动，交付新 APK；不上传 GitHub，不追加下一功能。手机安装和设置体验由用户实测。
