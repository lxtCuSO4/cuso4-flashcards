# Lunar Memory 使用指南

Lunar Memory 是一款在手机本地运行的闪卡应用。无需注册或登录，牌组导入、学习、练习、统计和备份均可离线完成。卡片和学习进度保存在本机，当前版本不提供账号同步功能。

## 首次使用

1. 获取 Lunar Memory APK 安装包并完成安装。当前安装包适用于 Android 8.0 及以上的 ARM64 手机，版本性质为开发试用版。
2. 打开应用，在首页点击「导入 .apkg 牌组」，选择已经保存在手机里的 Anki 牌组包。
3. 点击「确认并导入」，等待导入完成后查看结果，再点击「查看牌组」。
4. 基础卡、填空卡：回到「今日」点击「开始今日学习」，或在牌组内点击「学习这个牌组」。选择题：在牌组内点击「选择题练习」。

更新应用时，使用包名和签名一致的安装包进行覆盖安装，可保留已有数据。若安装失败，请保留原应用，避免因卸载造成数据丢失。建议更新前先导出本地备份。

## 四个主要页面

| 页面 | 主要功能 |
| --- | --- |
| 今日 | 查看当前可学卡片、今日已学和连续学习天数，开始正式学习，快速进入牌组 |
| 牌组 | 导入、新建和整理牌组，展开章节，编辑卡片，搜索及批量管理，顺序／随机练习与选择题练习 |
| 记录 | 查看学习统计、学习日历和评分分布，管理收藏及练习收藏卡片 |
| 我的 | 错题列表、收藏与专项练习，调整学习额度、外观和触觉反馈，设置本地提醒，管理存储、备份和恢复，填写问题反馈、查看 GitHub 仓库 |


## 导入 Anki 牌组

支持标准基础卡、填空卡、格式明确的单选／多选题、包内图片，以及旧版和新版压缩 `.apkg`。复杂自定义模板可能无法转换；导入结果会列出跳过的笔记或缺失媒体，请留意提示。牌组包和解压后总量均有 512 MB 上限。

选择题需包含题干、按行排列的连续 A–H 选项（2–8 项），背面以「答案：A」或「答案：AC」等方式明确标注答案。同时支持题干／独立选项／答案等已知字段。明确的单选／多选标记需与答案数量一致；没有题型标记时，根据有效答案个数识别。原解析、来源和图片会保留。答案缺失、选项不完整或题型冲突时，保留为基础卡并在导入结果中提示数量，不会自动推断缺失答案。

导入范围包括卡片内容和媒体，不包含 Anki 的复习排程。基础卡、填空卡从新卡状态开始记忆学习；选择题进入独立刷题流程。

遇到同名牌组时：

- 「建立副本」保留原牌组，并为新牌组名称添加后缀。
- 「合并追加」向原牌组追加卡片，不覆盖旧卡；重复导入同一个包会产生重复卡片。

导入期间请保持应用打开。若应用意外关闭，下次打开时会提示「上次导入未完成」；请重新选择原文件并执行导入。重新导入会从头处理文件，不会从中断百分比继续；此前已保存的牌组和学习进度会保留。

## 正式学习与评分

正式记忆学习适用于基础卡和填空卡。单选、多选题不参与 FSRS 或自定义自然日排程，不计入今日记忆学习额度和待学数量；原有历史记录保留。

阅读题目并回忆答案后，点击「显示答案」，根据实际记忆情况选择评分：

| 评分 | 适用情况 |
| --- | --- |
| 重来 | 无法回忆或回答错误 |
| 困难 | 能够回忆，但较为困难 |
| 良好 | 能够正常、独立地回忆答案 |
| 简单 | 能够迅速、准确地回忆答案 |

评分按钮同时显示预计复习间隔，默认由 FSRS 根据评分安排后续复习，也可在「我的 → 学习设置」选择自定义自然日策略。无法回忆时应选择「重来」；「困难」适用于能够回忆但过程较为困难的情况。如需更正评分，可在学习页点击「撤销上次评分」。

学习页还可以收藏或编辑当前卡片。编辑时会载入已有内容，保存返回后仍显示当前卡片；学习进度不会因文字修正而重置。编辑期间不计入本次答题耗时。来源信息会随答案展示（原卡片需要包含来源）。

暂时没有可学卡片时，可能是卡片尚未到期，或今日额度已用完；可以稍后继续，或使用随机练习。

## 背卡模式

进入「牌组 → 打开牌组 → 背卡模式」，可直接查阅题目和答案，无需先翻面或评分。基础卡同时显示正反面；填空卡显示完整原文，并突出填空内容；单选／多选题直接标出正确选项及解析，保留原选项顺序。

默认按章节顺序浏览，包含子章节；可切换「随机顺序」或关闭「包含子章节」，使用「上一条／下一条」翻阅。一条包含多个填空编号的笔记只出现一次。应用会在本机保存当前笔记、范围及随机排列，重新进入时继续阅读；内容删除后回到有效的笔记。

背卡不受卡片到期时间或每日额度限制，不写入学习评分、日历或排程。右上角可编辑、收藏当前内容；填空笔记的收藏对应其第一张卡。阅读位置随本地完整备份保存。

## 选择题练习与错题列表

进入「牌组 → 打开牌组 → 选择题练习」，只练习当前范围的单选题和多选题。默认顺序练习，按卡片建立顺序排列；也可切换「随机练习」。可选择是否包含子章节；本轮使用所选范围内全部题目，无需填写数量，轮内不重复。

选择题采用紧凑的一屏优先布局：题号、牌组信息和东方题签集中在顶部，选项使用字母徽标，收藏、编辑位于顶栏；「提交答案／查看解析」或「下一张」固定在底部。未作答时可从右上角「更多操作 → 跳过此题」跳过。

页面会按实际可用空间压缩留白，必要时临时缩小正文，最多缩小 25%，基准正文不低于 16 逻辑像素（原字号已经更小时保持原值）。临时适配不修改你保存的字号。超长题干、很多长选项或大字号仍可上下滑动，保留全部内容；常规题目尽量一屏显示。题目中的缩略图片可以点击放大，再关闭图片返回作答。

选择选项后点击「提交答案」，保存判分后会自动打开独立的「题目解析」页，显示你的答案、正确答案、错选／漏选和已有解析。单选题选对才算正确，多选题须完整选对，少选、多选或错选均判错。只有正式提交才记录判分；「跳过此题」不加入或清除错题。

解析页底部固定显示「返回题目」和「下一题」，无需滚动到长解析末尾。最后一题的按钮为「完成本轮」。也可使用左上角返回箭头或系统返回键回到当前题目，已选选项、排列和判分保持不变，题目页原有「下一张」仍可使用；点击「查看解析」可再次打开本题解析，不重复判分或更新错题。

未提交时也可点击题目页「查看解析」，此时本题标记为未作答，不新增或清除错题；看过答案后本题选项锁定，可继续下一题。解析为空时显示「本题未提供解析」，仍可继续练习。

提交错误答案后，题目自动进入「我的 → 错题列表」，重复答错累计当前错题次数。再次提交正确答案后，自动移出错题列表；以后再次答错会重新加入并重新计数。错题与收藏相互独立，答对不会取消收藏。

在错题列表中可筛选牌组及子章节，点击「错题专项练习」进行顺序或随机练习。点击收藏或错题列表里的选择题，也使用相同的紧凑预览页；预览中作答、查看解析不更新错题，解析页仅提供返回题目，返回后可以重新作答。背卡浏览也不更新错题。某轮开始后题目范围固定，下一轮按最新错题重新取题。

练习中可以收藏或编辑当前题目；仅改标签时保留作答，修改题目内容后重置当前题的作答。结束后显示本轮答对、答错和未作答数量。选择题练习不写入正式学习评分、排程、学习日历或每日额度，退出后保留题序、当前位置、选项与解析状态；再次进入点击「继续顺序练习」或「继续随机练习」即可恢复。错题、收藏在本机保存并纳入完整备份。

## 自由练习与收藏

「牌组 → 打开牌组 → 随机练习」可以自由抽卡，包含所有卡片类型和尚未到期的卡片。可切换顺序练习；默认包含子章节，练习范围内全部有效卡片，无需填写张数。同一轮不会重复出现同一张卡。

练习中点击「显示答案 → 下一张」，结束后可「再练一轮」。随机练习没有四项评分，不改变 FSRS、每日额度、正式学习统计或日历；退出或重启后保留本轮题序和位置。顺序与随机、牌组与收藏错题分别保存进度；「更多操作 → 切换练习方式」可切换，「从头练习」仅重置对应范围的练习。

需要重点复习的卡片可手动收藏。在「我的 → 我的收藏」或「记录 → 查看收藏」中，可按牌组或章节筛选、预览、取消收藏。选择「收藏随机练习」可练习全部类型，也可切换顺序；选择「收藏选择题练习」只练习收藏的单选／多选题，同样支持顺序和随机。自由练习、收藏练习中提交选择题，也遵循答错加入、答对移出错题列表的规则。收藏由用户手动管理，选择「重来」不会自动收藏卡片。

## 管理牌组与卡片

章节默认收起。点击牌组名称左侧箭头展开或收起，点击名称进入牌组；应用会记住展开选择。牌组右侧菜单支持重命名、新建子牌组、移动和删除。

在牌组内点击「新建卡片」，可创建以下类型的卡片：

- 基础卡：填写正面问题和背面答案。
- 填空卡：在原文中使用 `{{c1::需要记忆的内容}}`。例如：`首都是 {{c1::北京}}。` 不同编号如 c1、c2 会生成不同卡片，同一个编号对应同一张填空卡。
- 单选题：填写题干、2–8 个选项，勾选一个正确答案，可填写解析。
- 多选题：勾选至少两个正确答案；少选、多选或错选都判错。
- 可添加标签，在文字光标位置插入本地图片，再用「预览卡片」检查效果，最后点「保存卡片」。

选择题的题干、各选项、解析均可插入图片。默认保留选项顺序；打开「打乱选项」后每次作答重新排列，含「以上皆是」等顺序关系时请关闭。

作答时先选择选项，再点击「提交答案」，自动进入解析页查看正确答案、错选／漏选和解析；提交后无法更改选项。未提交就「查看解析」记为未作答。选择题独立练习不显示四项评分，也不写入 FSRS。收藏和错题预览同样可进入独立解析页，但不会写入错题或学习记录；编辑器预览仍在原页面显示解析，「直接看答案」记为未作答且不更新错题。编辑选择题时保留既有记录，编辑器不提供直接切换已有卡片类型的功能。

对于旧版已导入为基础卡的选择题，进入「牌组 → 打开牌组 → 识别已导入选择题 → 扫描基础卡」，核对单选／多选数量后，点击「转换为选择题 → 确认转换」。扫描范围包含子章节，仅在确认后执行修改；卡片 ID、学习进度、复习记录、收藏、标签、图片和原解析均会保留，无需删除或重新导入。已有选择题、填空卡和无法确定的基础卡保持原样。若扫描后编辑过卡片，请重新扫描后再确认转换。

支持插入 PNG、JPG、GIF、WebP，单张不超过 10 MiB、1600 万像素。编辑区的图片以标记显示，预览和学习时才显示图片。离开未保存的编辑会询问是否放弃；意外关闭应用会丢失未保存内容。

点击牌组中的卡片可进行编辑。删除操作会删除整条笔记、其生成的全部卡片及相应学习记录；一条填空笔记可能对应多张卡片，请在确认前核对删除范围。

## 搜索与批量管理

在「牌组」右上角点击搜索图标，可跨全部牌组搜索；在某个牌组右上角进入「搜索与批量管理」，默认只搜索该牌组。

可搜索正面、答案、来源等已存文字，并按牌组、类型、标签和收藏筛选。选中本页笔记后，可以批量移动、添加或移除标签、删除。每页 30 条，「全选本页」只选择当前页，换页或更改搜索条件会清空选择。

移动和标签修改保留学习进度。批量操作的单位是笔记，会影响该笔记生成的全部卡片。搜索目前是文字片段匹配，不是语义搜索，也不能搜索图片内的文字。

## 学习记录与设置

「记录」支持切换最近 7 天、30 天、90 天或全部记录，查看学习次数、卡片数、记录耗时、评分分布和连续天数。点击日历日期可查看当日详情。

同一张卡多次评分会计为多次学习；随机练习不计入。「非重来比例」来自自己的评分，不是考试正确率；记录耗时也可能包含停留时间。

「我的 → 学习设置」默认每日新卡 20 张、复习上限 200 张，FSRS 期望保持率 90%。建议首次使用时保留默认值，熟悉学习流程后按需调整。每日额度按各卡片所属牌组分别计算，父牌组和子章节不共用总额度。新设置在下一次进入学习时生效，不会立即重新安排已有到期时间。

「复习策略 → 排程方式」提供两种选择：

- FSRS 智能排程：保留原有行为，根据卡片记忆状态调整间隔，学习与重学可以出现分钟级步骤。
- 自定义自然日：按评分使用固定规则，默认「重来 10 分钟、困难 1 天、良好 3 天、简单 7 天」。可修改分钟数及天数，后三档天数须依次递增。此策略不预测记忆保持率。

自定义的「重来」从评分时刻起计；后三档在目标自然日零点到期，允许次日复习。例如 11 月 16 日 20:00 评分，默认四档分别为当日 20:10、11 月 17 日零点、11 月 19 日零点和 11 月 23 日零点。评分按钮会显示目标日期；答案显示期间跨过午夜时，会先更新日期并提示再次评分。

自然日沿用首次学习时记录的时区，与每日额度一致。切换策略不立即改写已有卡片的到期日，下一次进入学习后的评分才使用新策略；可以切回 FSRS，撤销仍能恢复评分前的进度。

「我的」还可以选择浅色、深色或跟随系统，并把触觉反馈设为明显、轻柔或关闭；实际震动感受取决于手机及系统设置。

## 应用内字体大小

进入「我的 → 字体大小」，分别调整两类文字：

- 界面文字：菜单、按钮和页面说明，可设为 80%–150%。
- 卡片阅读：题干、选项、答案和解析正文，可设为 80%–200%，适用于正式学习、自由练习、背卡和卡片预览。

拖动滑块会实时更新对应的预览，点击「保存字号」后才应用到整个应用。两项设置独立计算，不会把界面倍率再叠加到卡片正文。离开页面时未保存的预览调整不会生效。

100% 表示保持手机系统字号；如果系统使用大字体，应用会在此基础上应用所选比例。点击「恢复默认」会将两项预览恢复到 100%，再点击保存即可。图片以及图片里的文字不随字号设置缩放。

字号设置保存在本机，重新打开应用仍会保留，并随本地完整备份保存和恢复。

## 本地学习提醒

进入「我的 → 学习提醒」，开启提醒并设置每日提醒时间，按提示授予通知权限；可通过测试通知检查设置。提醒由手机本地安排。

系统省电和后台限制可能使提醒延后，强行停止应用后需要重新打开。换手机或恢复备份后，请重新检查并设置本机提醒。

## 备份、恢复与存储

建议定期进入「我的 → 备份与恢复 → 导出本地备份」，将 `.cuso4backup` 文件保存至应用以外的文件夹，并复制到电脑或其他设备保管。备份包括卡片、图片、牌组结构、收藏、错题列表、记忆学习进度、学习记录和应用学习／外观设置；本机通知安排需重新设置。

恢复时选择 `.cuso4backup` 并确认。恢复会整体替换当前数据，不是合并；操作前先备份当前内容。成功恢复后可通过「导出恢复前快照」另存上一次恢复前的数据，本机只保留最近一次快照。

备份文件未加密，请妥善保管。卸载应用或清除应用数据会导致本机内容丢失，需使用此前已导出至应用外的备份进行恢复。

新版可恢复旧版备份；本版备份使用数据库版本 2，以保存错题列表。1.1.0 及更早版本无法恢复本版新备份，请先更新至 1.1.1 或更新版本。升级应用会自动迁移原有数据。

本节介绍应用内手动备份。手机系统提供的备份和换机服务由系统设置控制，请按需检查相关配置。

「我的 → 存储管理」可查看空间占用并清理未被卡片引用的媒体。它不会自动修复缺失图片。

## 当前功能范围

当前版本支持离线导入 `.apkg` 和在应用内创建卡片；暂不支持应用内 PDF 转卡、导出 Anki `.apkg`、账号登录或云同步。`.cuso4backup` 为本应用的完整备份格式，不能作为 Anki 牌组使用。

## 问题反馈

进入「我的 → 问题反馈」，选择问题／建议／其他，填写标题和详情，联系方式为选填项。点击「打开邮件应用」后，收件人为 `lixingtong035@163.com`，请在邮件应用中核对内容并确认发送；打开邮件页面不代表邮件已发送。

填写表单无需联网，真正投递需要手机已安装并配置好邮件应用、且邮件应用能够联网。未安装邮件应用或打开失败时，可以点「复制反馈内容」，再自行粘贴发送；复制内容包含收件邮箱。

应用不会自动上传牌组、图片或学习记录。打开邮件应用后返回，或调用失败时，当前表单内容会保留；离开反馈页时会提示确认，离开页面或关闭应用后不保留表单。遇到问题时，请保留应用及已有数据，并在反馈中注明操作步骤、错误提示和手机型号。
