# 背卡模式与学习中编辑

## 背卡

入口：「牌组 → 打开牌组 → 背卡模式」。默认显示答案，按章节、笔记顺序阅读，包含子章节；支持随机顺序、上一条、下一条、编辑、收藏和本地位置恢复。每条填空笔记只显示一次，所有填空答案同时可见；选择题沿用原选项顺序，突出正确项和解析，不显示作答判分。

阅读状态保存在 `app_settings` 的 `recitation:<deckId>`，随机顺序保存笔记 ID 列表，恢复时移除失效笔记、补入新笔记。位置和范围可随现有完整备份恢复；不修改卡片排程、复习日志或每日额度。收藏是明确操作，填空笔记对应第一张卡的收藏状态。

## 编辑页修复

复现路径：「首页 → 学习 → 编辑卡片」。原编辑路由位于底部标签导航内部，从独立学习页压入时会重复压入该导航容器，产生重复页面键断言，表现为整页空白。编辑路由移到独立根路由，保留原 URL。

返回学习时重新读取当前卡片，不重建学习会话，保留本轮次数及撤销入口；卡片删除后才读取下一张。编辑期间停止答题计时。读取失败显示错误和重试，不展示可保存的空表单。

## 手机验收

覆盖安装前导出本地备份。在学习页分别编辑基础、填空、单选、多选卡，核对原内容、保存、返回同一张及评分／撤销。进入背卡模式，检查图片、正确答案、前后翻阅、子章节与随机开关，退出重进后位置保持。浏览前后核对学习记录，不应新增评分。真实手机安装和触觉效果仍需验收。
