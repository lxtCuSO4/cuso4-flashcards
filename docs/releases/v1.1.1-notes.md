# Lunar Memory v1.1.1

单选题、多选题现采用独立刷题流程，不再进入 FSRS 或自定义自然日排程。基础卡、填空卡继续使用原有记忆策略。

- 牌组内支持顺序练习、随机练习及子章节范围选择。
- 答错自动加入错题列表，重新答对后自动移出；再次答错可重新加入。
- 「我的 → 错题列表」支持专项练习；收藏的选择题也可单独顺序／随机练习。
- 练习中支持收藏、编辑，错题记录纳入本地完整备份；旧数据库和旧备份可以升级。

附件包含 ARM64 APK 和使用指南。适用于 Android 8.0 及以上，安装包约 23 MB，全部核心功能可离线使用。

应用版本为 1.1.1，内部版本码为 4，沿用原有包名和签名，可覆盖先前版本及本地 1.2.0 试构建。更新前建议导出本地备份；1.1.0 及更早版本无法恢复本版新备份。

本版仍为开发预览版，已完成针对性检查和安装包签名校验，手机上的覆盖安装与显示观感待实际使用验收。PDF 制卡不包含在本次发布中。
