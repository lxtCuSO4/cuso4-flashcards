# 学习统计与日历

在底部导航进入“记录”。已有学习记录会自动统计，不需要重新导入牌组。所有数据来自本机数据库，不上传。

## 使用

- 顶部切换最近 7 天、30 天、90 天或全部时间；这些范围包含今天。
- 汇总显示学习次数、去重卡片张数、记录耗时和非重来比例，同时显示所选范围内的学习天数及当前连续学习天数。
- 月历显示每日学习强度，可切换月份、回到本月，点过去或今天的日期打开当日详情。月历月份与顶部统计范围独立；未来日期不可操作。
- 日历按 0、1–9、10–29、30+ 次分档，边框标出今天。日期有包含日期／次数的读屏标签，所有日期触控区至少 48dp。窄屏日历自身可以左右滚动。
- 学习趋势按连续日期分段汇总，每段标明起止日期和学习次数，补入没有记录的日期；最多显示 12 段。四项评分分布同时提供文字和条形显示。
- “查看收藏”入口保留在记录页上方。查看统计／详情不会消耗每日额度或修改 FSRS 排程。

## 统计口径

| 指标 | 含义 |
| --- | --- |
| 学习次数 | 评分日志条数，包括新卡、学习、复习及重学；同一张卡多次评分计多次 |
| 学习卡片 | 所选范围内按卡片 ID 去重，跨日重复学习仍计一张 |
| 记录耗时 | 评分时记录的会话耗时之和，可能包含停留或后台时间，不等同于纯专注时长 |
| 非重来比例 | 没有选择“重来”的次数 ÷ 全部评分次数，无记录显示“—”；这是自评比例，并非客观测验正确率 |
| 当前连续天数 | 今天有评分时从今天向前连续计数；今天尚未学习时从昨天起算，缺一天即中断；不受顶部时间范围筛选限制 |

日期沿用每日额度的固定学习日时区（第一次学习时记录的设备偏移），以该时区零点分日。尚未有该设置时只读使用当前偏移；浏览记录本身不写入设置或固定时区。午夜、从后台回到应用时刷新日期；打开某日详情后，即使跨月仍保留该日数据。

仅统计当前保留的评分记录。撤销会删除对应日志并刷新统计；删除卡片／牌组级联删除的日志也会从统计中消失。`.apkg` 导入会重新开始学习，因此导入本身不产生历史统计；应用完整备份／恢复中的复习日志可以用于统计。

## 实现与边界

数据库在只读事务中按时间范围与日期聚合，使用已有的 reviews_time 索引，不将原始日志全集加载到界面，不增加数据库表或第三方依赖。连续天数仅读取按日分组的历史日期。图表分段限制为 12，月历最多 42 格；具体运行性能仍需在用户实际数据量与手机上体验。

## 最小手机验收（尚待用户操作）

1. 覆盖安装新 APK，保留现有数据，进入“记录”，检查已有评分是否显示。
2. 完成一次学习评分，再看次数及对应日期；撤销后应恢复。查看日期详情不应增加学习次数。
3. 切换 7／30／90 天及全部，切换月历并点选有记录／无记录的日期，检查当日详情和四项分布。
4. 检查手机大字体、横屏、深色和日期触觉反馈；较窄屏幕可横向滚动日历。该包仍为 ARM64 本地测试签名版本。
