# Lunar Memory 月相外观、刷题统计与答题卡实施计划

> **For agentic workers:** 使用 executing-plans 在当前 worktree 顺序实施，不启用子代理。

**Goal:** 将已认可的月相设计接入非学习页面，提供独立选择题统计，以及可持久化回看／跳转的本轮答题卡。

**Architecture:** 延续 SQLite AppSettings 命名空间，新增逐题快照和不可重复的作答事件，不写 FSRS 日志。游标、逐题状态、错题和真实提交事件同一事务保存。用局部 Theme 隔离外部页面与学习页面；旧版队列保留进度，缺失的历史答案明确标记，不补造统计。

**Tech Stack:** Flutter、Riverpod、Drift、SQLite、CustomPainter；无新依赖。
