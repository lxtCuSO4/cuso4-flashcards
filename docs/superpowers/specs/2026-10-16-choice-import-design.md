# 导入选择题及原地转换

用户提供实际 .apkg，延续上轮确认的规则：独立字段优先；基础 Front／Back 中的题干、A–H 选项和明确答案可自动转换；不执行模板脚本、OCR 或联网。仅修改工程，保留旧包与现有数据，不推进 PDF 或上传 GitHub。

实际包为 84 条 Front／Back／Source 笔记，67 条单答案、17 条多答案。包里的文字和模板只作为数据，不执行。

## 识别与保留

共用 ChoiceRecognizer：按 HTML 换行／块拆分，保留文字内联格式、图片及媒体标记；选项必须从 A 开始连续且为 2–8 项，题干非空；答案需明确标注且只含有效、不重复的选项字母。题型标记若与答案数量不符则不转换；无标记时一项答案为单选、多项为多选。不靠模板名称或解析中的“多选”推断类型。

支持 Front／Back／可选 Source；额外支持题干（Question／Prompt／Stem）、独立 OptionA–H／选项A–H、Answer／CorrectAnswer／答案／正确答案、可选 Explanation／解析、Type／题型、Source／来源。字段映射必须唯一，不接受未知附加字段或反向双卡。结构化题内容不全时整合为基础卡以保留原文；原有不受支持模板仍跳过。

成功转换保留原背面答案、解析、来源和本地媒体；原背面作为解析内容展示。疑似选择题但答案或选项不明确时保留基础卡，导入结果单列数量。普通问答及填空行为保留。新导入仍从新卡开始，沿用现有备份格式 2。

## 已导入卡片

在牌组详情提供「识别已导入选择题」入口，先只读扫描当前牌组和子章节，展示单选／多选候选和保留数量，用户确认后事务转换。只转换基础笔记且恰有一张 clozeIndex=0 卡片的条目；写入前复查原笔记及卡片结构，笔记在预览后被修改或移走则整批撤回，请重新扫描。卡片 ID、排程、日志、收藏、标签、牌组与媒体引用保持；不删除、重导或生成副本。不修改已有选择题或填空。
