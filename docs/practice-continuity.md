# 练习续练与数量简化

日期：2026-11-20。版本：1.1.5+8。

进入牌组、收藏或错题的练习入口，选择顺序或随机方式即可开始。无需填写数量，也没有默认 20 张或每轮 500 张限制；本轮使用所选范围的全部有效卡片。只保存卡片 ID 队列，题干和媒体按当前卡片读取。

已有记录时按钮显示「继续顺序练习」或「继续随机练习」，并显示上次位置。继续后保留题序、未提交选项、选项排列、答案显示状态及解析页位置。已经提交的题目不重复判分或增加错题次数。

顺序、随机、不同牌组、是否包含子章节、收藏与错题各有独立进度。每个入口记住最后使用的练习方式和章节开关。已完成的轮次可查看结果；「再练一轮」重新读取当前题库并生成新队列。

练习内的「更多操作 → 切换练习方式」可返回入口，不清除已保存进度。入口的「从头练习」需要确认，只重置当前范围与方式的练习记录，不删除收藏、错题或正式排程。

本轮不会因新增卡片而插入或重新打乱，新增内容在下一轮加入。已删除或已不符合范围的待答卡自动跳过；已经提交并从错题列表移出的当前题仍可查看原解析。

编辑当前题目后，若题目内容未变（如只改标签），保留作答状态。若题干、选项、答案或解析内容改变，重置当前题的选项和提交状态，并核对新版本后再作答，其他题目的进度保留。

练习会话保存在 SQLite 的独立 AppSettings 键中，队列只在新一轮写入，游标和答案随操作更新。判分、错题更新及提交进度位于同一事务。数据库版本和备份格式不变，完整备份自动包含练习进度；旧备份没有这些记录时正常从新一轮开始。

正式记忆的四档评分栏按按钮底色分别配置前景色，改善浅色主题「良好」与「重来」的可读性。四档布局与评分语义保持一致。

以上为 1.1.5 的历史交付范围。1.1.6 已进一步接入月相外观、选择题统计和逐题答题卡，详见 `docs/lunar-records-answer-sheet.md`。编辑草稿恢复、回收站与 PDF 制卡仍未实现。
