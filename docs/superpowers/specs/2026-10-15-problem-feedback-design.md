# 问题反馈

在选择题完成后实现；PDF 转卡组暂停。沿用永远亭主题，在「我的」增加「问题反馈」入口。

## 本地表单与发送

类别为问题、建议、其他；标题与详情必填，联系方式可选。表单只使用用户主动填写的内容，不自动读取设备身份、牌组、数据库或日志。收件人固定为 2791398676@qq.com。

使用 Android ACTION_SENDTO 的 mailto URI 打开外部邮件应用，带上编码后的主题、正文和收件人。按钮为「打开邮件应用」，明确由用户在邮件应用确认发送，邮件应用联网后才能投递。没有应用或打开失败时显示可复制的反馈文字及邮箱；不声称已发送。打开或失败后均保留表单，离开未保存内容时提示确认。表单内容只在当前页面内存保留。

沿用项目按钮反馈、大字号及深色适配，不引入联网权限、服务端或依赖包。

先验证空表单不能发起操作、中文/特殊字符正确传给原生桥、无邮件客户端时可复制且保留内容，再实现页面、路由和 Android 桥。与选择题一起运行必要回归，最终仅构建一次 ARM64 APK；不发送测试邮件。
