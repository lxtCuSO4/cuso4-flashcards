# Lunar Memory：导入恢复与新图标

更新：2026-10-15。

## 导入被意外终止后

下次启动会在读取本地数据前识别仍处于运行状态的导入任务，SQLite 回滚未提交内容，应用将任务标记为中断。首页和导入页显示“上次导入未完成”，用户重新选择原 `.apkg` 文件后再确认导入。不会自动续传、自动重新导入或记住外部文件路径。

已经提交的牌组、卡片、FSRS 进度和媒体保留。已完成导入仅遗留暂存目录时，不会要求重导，避免重复卡片。“知道了”会持久隐藏提示；旧提示的确认不能清除随后出现的新提示。

## 清理范围

只清理应用私有 `media/.imports` 下可识别的 `job_*` 和 `cuso4_apkg_*` 暂存目录。移动新媒体前写入持久日志，启动恢复只清理日志记录的、没有数据库媒体记录且没有任何笔记实际引用的普通哈希文件。

未知目录、链接、异常日志或无法确认安全的文件保留，清理失败不会阻断正常学习，下次启动重试。旧版本没有日志的暂存仅清理目录，不推测媒体根目录内文件归属。整个媒体库的未使用文件清理由“我的 → 存储管理”另行操作。

## 名称与图标

应用显示名称改为 **Lunar Memory**，使用用户提供的铃仙图片。原图只读复制至 `assets/branding/launcher-source.jpg`，SHA256：`E3904640E094BA132E8B95EC6A2E37873D9E17204F5751EB0B98CD76A7169EE8`。

`tool/generate_launcher_icons.py` 使用 Pillow 生成五种密度的普通／圆形图标、Android 8+ 自适应前景和预览。保留像素风格及原图可见内容，白底留白适配圆形和圆角裁切。通知栏小图标沿用独立的卡片符号。

应用标识仍为 `com.cuso4.flashcards`，数据库和 `.cuso4backup` 格式、旧备份文件命名及签名保留，以便覆盖升级。新版本显示名称不影响旧数据或备份恢复。

## 手机验收

1. 直接覆盖安装新 APK，保留原应用及数据。核对桌面显示 Lunar Memory 与铃仙图标；若桌面暂未刷新，先正常重启手机，不清除应用数据。
2. 确认已有牌组、图片、收藏、评分／撤销及学习进度仍可使用。
3. 先导出本地备份；选用临时测试牌组，在导入读取或保存阶段强行停止应用，再打开。应显示中断提示，旧数据保持；重新选择并导入一次，应正常完成。
4. 点击“知道了”，重开应用，已确认且没有新中断的提示应保持隐藏。
5. 正常导入完成后重开，不应误报未完成。深色及放大字体下按钮和提示应可滚动访问。

当前仍是开发测试签名、ARM64 安装包。电脑验证不代替真实安卓强停、桌面缓存和多机型验收；正式公开发布签名仍待完成。
