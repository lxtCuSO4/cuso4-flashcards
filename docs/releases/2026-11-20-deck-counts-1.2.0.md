# Lunar Memory 1.2.0 牌组数量修正

日期：2026-11-20（Asia/Shanghai）；用户指定版本名 1.2.0，内部版本码 10。

## 修正内容

旧版牌组列表只按笔记直属牌组统计卡片，卡片分布在章节内时，父牌组会误导性地显示“0 张”。

新版在一次查询中汇总每个牌组及所有后代章节的卡片数量，并统计子章节数。父牌组显示「共 N 张卡片 · 含 X 个子章节」；X 包含各层嵌套小节与空章节，不包含当前牌组本身。没有子章节的牌组显示自身卡片数。填空笔记按实际生成的卡片数量计算。

展开／收起不改变统计。订阅牌组、笔记和卡片变化，新增卡片、移动章节、删除章节或笔记后自动刷新。统计读取中、读取失败或新增牌组计数尚未到达时使用明确状态提示，不将未知数量显示为 0；读取失败时提供重新统计入口。

本次只变更查询与显示，不改写用户的牌组、卡片、媒体或学习进度。数据库版本与备份格式不变；保留上一版月相外观、刷题统计及答题卡功能。反馈内容和备份清单中的应用版本同步为 1.2.0+10。
