# Lunar Memory v1.2.0

本版包含自 v1.1.3 以来的界面与练习改进，并修正分章节牌组显示“0 张”的问题。

- 牌组列表显示「共 N 张卡片 · 含 X 个子章节」，累计所有下级章节和嵌套小节；新增、移动或删除后自动更新。统计加载中或失败时不再误报为零。
- 非学习页面接入月相外观：首页月盘、月相序列、牌组书脊与分组工具页面，支持浅色和深色；学习、答题、解析与背卡保留原阅读布局。
- 顺序／随机练习取消数量输入，使用当前范围全部有效卡片，退出后保留本轮题序、位置、选项排列、未提交选择与解析状态。
- 新增本轮答题卡：查看对错、未答、已看答案和收藏标记，筛选并跳转题号、回看已答题、返回本轮结果；回看不重复计分。
- 新增独立刷题统计：7／30／90 天及全部的题次、正确率、对错数量、前台作答用时、日历和日期详情。仅真实提交计入，不改变 FSRS、记忆学习记录和每日额度。
- 选择题采用一屏优先布局，必要时临时缩小正文；超长内容保留滚动，底部操作按钮固定。
- 继续支持字体大小调节、选择题独立解析、错题答对自动移出、收藏专项练习与完整本地备份。

旧版进度和汇总保留，旧版没有保存的逐题答案及历史作答不补造；需要重新作答时新开一轮。PDF 转卡不包含在本次发布中。

附件为 Android 8.0 及以上 ARM64 APK（约 23.3 MB）和正式使用指南。应用版本为 `1.2.0`，内部版本码 `10`，包名与签名沿用旧版，可覆盖安装，建议更新前先导出备份。数据库与备份格式均保持版本 2。

本版仍为开发预览版，沿用现有开发测试签名。相关回归、静态分析、离线构建和签名检查通过；实际手机覆盖安装及多机型兼容仍待设备验收。
