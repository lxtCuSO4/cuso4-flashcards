# Lunar Memory

本地使用的 Android 闪卡应用，支持 Android 8.0 及以上，无需服务器或账户。

[下载 v1.1.3 APK 与使用指南](https://github.com/lxtCuSO4/cuso4-flashcards/releases/tag/v1.1.3)。本版为开发预览版，适用于 Android 8.0 及以上的 ARM64 手机，约 23.1 MB。覆盖安装可保留已有数据，建议更新前先导出本地备份。

支持基础卡、填空卡、单选题、多选题、文字与图片 `.apkg` 导入、FSRS 学习、随机练习、收藏、学习日历、跨牌组搜索、批量管理、本地提醒、存储管理及备份恢复。导入异常中断后，下次启动会安全清理暂存并提示重新选择牌组包。

1.2.0 本地修正版修正父牌组显示“0 张”的计数口径：列表累计当前牌组和所有下级章节卡片，显示「共 N 张卡片 · 含 X 个子章节」。章节数包含嵌套小节；展开、收起不影响数量，新增、移动与删除后自动刷新。保留 1.1.6 的月相外观、独立刷题统计与答题卡。此版本尚未上传 GitHub。

1.1.6 本地开发版接入月相外观、独立刷题统计和本轮答题卡：非学习页面采用纸色／墨青与月盘、月相题签，保留原学习阅读页面；刷题可查看题次、正确率、前台用时和日历详情；答题卡支持筛选与跳转、恢复逐题选项、完成后回看，回看不重复计分。顺序／随机练习无需输入数量，退出可继续原轮次。真实刷题统计从本版本开始记录，旧版进度保留而不补造历史答案。详见 [功能说明](docs/lunar-records-answer-sheet.md)。此更新尚未发布至 GitHub，以上下载链接仍为此前已发布版本。

1.1.3 新增「我的 → 字体大小」：分别调节界面文字（80%–150%）和卡片阅读文字（80%–200%），支持实时预览、保存和恢复默认，100% 跟随系统字号。设置保存在本机并随完整备份恢复。本版同时包含独立选择题解析页：提交后自动打开，底部固定「返回题目／下一题」，题目页原有按钮保留。

1.1.0 新增答案默认可见的背卡模式，以及可选的自定义自然日策略（默认重来 10 分钟，困难／良好／简单 1／3／7 天），并修复学习中打开编辑页空白的问题。默认 FSRS 保留原有行为；设置只影响之后的评分，背卡浏览不改变学习进度。

选择题支持 2–8 个选项、图片、解析；多选按答案集合完全一致判定。1.1.1 将选择题独立为顺序／随机刷题，不再进入记忆排程；答错加入错题列表，答对自动移出，支持错题和收藏选择题专项练习。`.apkg` 中题干、连续 A–H 选项和明确答案齐全时自动识别单选／多选，无法确定时保留基础卡；不执行模板脚本。已有基础卡可在牌组内扫描并确认转换，保留原记录。新备份使用数据库版本 2 保存错题，新版仍可恢复旧备份。

「我的 → 问题反馈」可离线填写表单，再交给手机邮件发送。用户需在邮件应用确认并联网投递；没有客户端可复制内容。应用自身不联网，不自动附加用户数据。

使用 Flutter、Drift／SQLite。内部应用标识和备份格式保留，以支持覆盖升级和旧数据。
