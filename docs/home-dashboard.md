# 首页今日概览

打开底部“今日”。所有数据来自本机数据库，查看首页不修改卡片排程、日志或每日额度，也不会提前固定学习日时区。

## 显示内容

- **现在可学**：目前已到期且符合各牌组剩余额度的卡片总数，不受单次学习批次 50 张限制。
- **待复习**：到期的复习状态卡片，已扣除所属牌组今天用过的复习额度。
- **学习中**：到期的学习／重新学习卡片；每日新卡或复习额度为 0 时，这部分仍可继续学习。
- **可学新卡**：到期的新卡，已扣除各所属牌组今天用过的新卡额度。父子牌组额度独立。
- **今日已学**：学习日内按评分日志去重的卡片张数。旁边的评分次数可以大于张数，同一卡片反复学习不重复增加张数。
- **当前连续天数**：今天有学习则从今天算，否则从昨天算；遇到没有评分记录的日期中断，与记录页一致。
- **本机知识库**：所有卡片和牌组（含章节）数量，预览最多五个顶层牌组，按名称排序，其卡片数包含后代章节。点击牌组进入原卡片页；“查看全部牌组”保留原默认收起的章节结构。

已学卡仍可能需要再次学习，因此没有用“已学 + 当前待学”构造固定每日目标或完成百分比。暂停或耗尽额度时也不会误报所有学习已完成。

## 操作与刷新

“开始今日学习”进入已有 FSRS 学习界面；没有可学卡时禁用并解释原因，可进入学习设置调整额度。若还有符合额度的未来卡，显示其下一次到期时间；时间按固定学习日时区展示，不是倒计时，也不保证未来学习内容不会因后续评分改变。

空库提供 `.apkg` 导入和新建第一张卡片入口。已有空牌组时在第一个顶层牌组新建；没有牌组时先输入牌组名称，再进入卡片编辑器。取消新建卡片不会自动删除已创建的空牌组。

评分、撤销、卡片或牌组改动、学习设置保存会刷新数据；下一次可学到期、学习日零点、恢复前台和退出学习也会刷新。右上角可手动刷新，读取失败可以重试。数据错误不以默认零替代。

日期沿用第一次学习固定的 `studyDayOffsetMinutes`。尚未固定时采用设备当前偏移，不因浏览首页写入设置。撤销及删除卡片／牌组引起的日志删除会改变已学统计；导入 `.apkg` 重新开始学习，不会产生历史评分日志。

## 手机最小验收（尚待执行）

1. 覆盖安装新 APK，保留数据；打开“今日”，核对可学数及三类明细。
2. 开始学习并评分，退出后检查“今日已学”和评分次数；在学习页撤销后返回检查回退。
3. 更改每日新卡／复习额度，返回首页核对变化。额度为 0 时仍应允许已到期的学习中卡片。
4. 检查首页牌组数量包含其章节，但首页只预览顶层；进入“查看全部牌组”检查章节收起状态保留。
5. 检查深色、大字体和横屏；暂时无可学卡片时检查原因提示，以及到期后或后台返回的数据刷新。

当前包仍为 ARM64、本地 Android Debug 测试签名。测试和构建通过不能替代真实手机运行或大数据量性能验证。
