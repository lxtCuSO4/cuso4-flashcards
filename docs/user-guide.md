# Lunar Memory 使用指南

一款在手机本地使用的闪卡应用。无需注册或登录，导入、学习、练习、统计和备份都可以离线完成。卡片和学习进度保存在本机，目前没有账号同步。

## 第一次使用

1. 安装朋友发来的 Lunar Memory APK。当前安装包适用于 Android 8.0 及以上的 ARM64 手机，是开发试用版。
2. 打开应用，在首页点击「导入 .apkg 牌组」，选择已经保存在手机里的 Anki 牌组包。
3. 点击「确认并导入」，等待完成后查看导入结果，再点「查看牌组」。
4. 回到「今日」点击「开始今日学习」，或在某个牌组内点击「学习这个牌组」。

更新应用时直接覆盖安装，保留已有数据。安装失败时先保留旧应用，不要靠卸载解决；建议更新前先导出一份备份。

## 四个主要页面

| 页面 | 可以做什么 |
| --- | --- |
| 今日 | 看现在可学的卡片、今日已学和连续学习天数，开始正式学习，快速进入牌组 |
| 牌组 | 导入、新建和整理牌组，展开章节，编辑卡片，搜索及批量管理，随机练习 |
| 记录 | 看学习统计、学习日历、评分分布，查看收藏和练习收藏卡片 |
| 我的 | 调整学习额度、外观和触觉反馈，设置本地提醒，管理存储、备份和恢复 |

「寺子屋」「迷途竹林」「永远亭」「铃仙的书签」等是固定的东方主题装饰，实际操作仍以页面上的功能名称为准。

## 导入 Anki 牌组

支持标准基础卡、填空卡、包内图片，以及旧版和新版压缩 `.apkg`。复杂自定义模板可能无法转换；导入结果会列出跳过的笔记或缺失媒体，请留意提示。牌组包和解压后总量均有 512 MB 上限。

导入只带入卡片内容和媒体，不带入 Anki 的复习排程；新导入的卡片都从新卡开始。

遇到同名牌组时：

- 「建立副本」保留原牌组，给新牌组加后缀。
- 「合并追加」向原牌组追加卡片，不覆盖旧卡；重复导入同一个包会产生重复卡片。

导入期间保持应用打开。若被意外关闭，下次打开会提示「上次导入未完成」；重新选择原文件并导入即可。这是重新导入，不是从中断百分比继续；已经保存的旧牌组和学习进度会保留。

## 正式学习：先回想，再评分

先看问题，在心里回想答案，再点「显示答案」。按实际记忆情况选择：

| 评分 | 什么时候选 |
| --- | --- |
| 重来 | 忘记了，或想错了 |
| 困难 | 想起来了，但很吃力 |
| 良好 | 正常、独立地想起答案 |
| 简单 | 几乎不费力就能回答 |

按钮同时显示预计复习间隔，FSRS 会根据评分安排后续复习。忘记时选「重来」；「困难」适用于确实想起来的情况。点错后可在学习页点击「撤销上次评分」。

学习页还可以收藏或编辑当前卡片。来源信息会随答案展示（原卡片需要包含来源）。

暂时没有可学卡片时，可能是卡片尚未到期，或今日额度已用完；可以稍后继续，或使用随机练习。

## 随机练习与收藏

「牌组 → 打开牌组 → 随机练习」可以自由抽卡，包含尚未到期的卡片。默认包含子章节、抽取 20 张，可调整为 1–500 张；数量不足时使用范围内全部卡片。同一轮不会重复出现同一张卡。

练习中点击「显示答案 → 下一张」，结束后可「再练一轮」。随机练习没有四项评分，不改变 FSRS、每日额度、正式学习统计或日历；退出后不保留本轮临时进度。

难记的卡片可手动收藏。在「记录 → 查看收藏」按牌组或章节筛选，预览、取消收藏，或选择「收藏随机练习」集中巩固。收藏由自己决定，选「重来」不等于自动收藏。

## 管理牌组与卡片

章节默认收起。点击牌组名称左侧箭头展开或收起，点击名称进入牌组；应用会记住展开选择。牌组右侧菜单支持重命名、新建子牌组、移动和删除。

在牌组内点「新建卡片」：

- 基础卡：填写正面问题和背面答案。
- 填空卡：在原文中使用 `{{c1::需要记忆的内容}}`。例如：`首都是 {{c1::北京}}。` 不同编号如 c1、c2 会生成不同卡片，同一个编号对应同一张填空卡。
- 可添加标签，在文字光标位置插入本地图片，再用「预览卡片」检查效果，最后点「保存卡片」。

支持插入 PNG、JPG、GIF、WebP，单张不超过 10 MiB、1600 万像素。编辑区的图片以标记显示，预览和学习时才显示图片。离开未保存的编辑会询问是否放弃；意外关闭应用会丢失未保存内容。

点击牌组中的卡片可编辑。删除操作会删除整条笔记、它生成的全部卡片以及相应学习记录；一条填空笔记可能对应多张卡，请在确认前看清范围。

## 搜索与批量管理

在「牌组」右上角点击搜索图标，可跨全部牌组搜索；在某个牌组右上角进入「搜索与批量管理」，默认只搜索该牌组。

可搜索正面、答案、来源等已存文字，并按牌组、类型、标签和收藏筛选。选中本页笔记后，可以批量移动、添加或移除标签、删除。每页 30 条，「全选本页」只选择当前页，换页或更改搜索条件会清空选择。

移动和标签修改保留学习进度。批量操作的单位是笔记，会影响该笔记生成的全部卡片。搜索目前是文字片段匹配，不是语义搜索，也不能搜索图片内的文字。

## 学习记录与设置

「记录」可以切换最近 7 天、30 天、90 天或全部，查看学习次数、卡片数、记录耗时、评分分布和连续天数。点击日历日期可看当天详情。

同一张卡多次评分会计为多次学习；随机练习不计入。「非重来比例」来自自己的评分，不是考试正确率；记录耗时也可能包含停留时间。

「我的 → 学习设置」默认每日新卡 20 张、复习上限 200 张，FSRS 期望保持率 90%。建议先用默认值，习惯后再调整。每日额度按各卡片所属牌组分别计算，父牌组和子章节不共用一份总额度。新设置在下一次进入学习时生效，不会立即重排已有到期时间。

「我的」还可以选择浅色、深色或跟随系统，并把触觉反馈设为明显、轻柔或关闭；实际震动感受取决于手机及系统设置。

## 本地学习提醒

进入「我的 → 学习提醒」，开启后选每日时间，按提示允许通知；可以先发送测试通知。提醒完全由手机本地安排。

系统省电和后台限制可能使提醒延后，强行停止应用后需要重新打开。换手机或恢复备份后，请重新检查并设置本机提醒。

## 备份、恢复与存储

定期进入「我的 → 备份与恢复 → 导出本地备份」，把 `.cuso4backup` 保存到应用以外的文件夹，再自行复制到电脑或其他设备保管。备份包括卡片、图片、牌组结构、收藏、FSRS 进度、学习记录和应用学习／外观设置；本机通知安排需重新设置。

恢复时选择 `.cuso4backup` 并确认。恢复会整体替换当前数据，不是合并；操作前先备份当前内容。成功恢复后可通过「导出恢复前快照」另存上一次恢复前的数据，本机只保留最近一次快照。

备份文件未加密，请自行妥善保管。卸载应用或清除应用数据会丢失本机内容，只有已经导出到应用外的备份才能用来找回。

这里介绍的是应用内手动备份；手机系统自带的备份和换机服务由手机设置控制，请自行检查。

「我的 → 存储管理」可查看空间占用并清理未被卡片引用的媒体。它不会自动修复缺失图片。

## 当前范围

当前 APK 可离线导入 `.apkg` 和在应用内制卡；暂不支持应用内 PDF 转卡、导出 Anki `.apkg`、账号登录或云同步。`.cuso4backup` 是本应用的完整备份，不能当作 Anki 牌组使用。

遇到问题时，先保留应用和已有数据，记录操作步骤、错误提示及手机型号，再反馈给分享安装包的朋友。
