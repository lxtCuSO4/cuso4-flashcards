## 开关与数据

在「我的 → 东方主题装饰」切换，默认开启。关闭时题签和自身留白一同隐藏，重开应用保留选择。写入失败时保留原值并显示重试提示；保存期间禁止重复切换。按键沿用触觉反馈设置。

偏好存入现有 `app_settings` 表的 `touhouDecorations` 键，值为 `true`／`false`。数据库仍为版本 1，现有完整备份会包含该偏好；旧备份没有此键时默认开启。卡片、学习进度、FSRS、导入恢复及桌面图标均沿用原实现。

## 手机验收

直接覆盖安装 `build/releases/lunar-memory-touhou-labels-arm64.apk`，无需卸载或重新导入牌组。

1. 浏览今日、牌组详情、随机练习、记录、收藏、我的与备份页，检查表中题签；进入正式学习检查「寺子屋 · 温习」位于卡面之外。
2. 在「我的」关闭装饰，返回上述页面检查题签及其留白消失；退出重开后仍关闭，再开启检查恢复。
3. 切换浅色／深色、放大系统字体及旋转手机，检查题签换行、正文滚动，以及显示答案、四项评分和撤销仍可操作。

电脑已验证开关真实数据库持久化、跨页面更新、写入失败及相关页面回归；真实手机观感、触觉和安装仍待上述验收。此包继续使用原 Android Debug 测试证书，正式公开发布签名和多机型测试另行安排。
