# 牌组随机练习

进入「牌组」→ 点开牌组名称 →「随机练习」。默认包含所有子章节；可以关闭「包含子章节」。本轮练习所选范围内全部有效卡片，无需填写数量，没有每轮 500 张限制。只包含子章节的父牌组需要打开该选项。

仅练习收藏时，进入「记录 → 查看收藏」，选择牌组范围并点「收藏随机练习」。它使用相同的练习流程，但只从当前范围内的收藏抽取，具体见 favorite-practice.md。

先看问题并回想，再点「显示答案」；之后点「下一张」，最后一张点「完成本轮」。使用与正式学习相同的本地文字、图片和填空渲染方式，答案中的补充内容和来源仅在揭示答案后出现。练习卡片不提供 FSRS 四项评分。

每轮开始时一次性生成随机卡片顺序，推进时不重新抽取。同一轮每张卡片最多一次；同一笔记不同填空编号是不同卡片，可以在同一轮出现。「再练一轮」重新随机抽取，因此不同轮次可能遇到相同卡片。「调整练习设置」或练习内的「切换练习方式」可以修改范围与顺序。已有进度显示「继续练习」；「从头练习」需要确认，仅重置对应范围和方式的练习进度。

抽取范围包含新卡、已学卡和未到期卡，不受正式学习的每日额度限制。练习独立保存题序、位置和作答状态，不更新 FSRS 到期时间、稳定性、难度、学习状态、学习次数、遗忘次数、收藏、每日额度、学习日志、首页已学数量、连续天数和学习日历。练习是自由巩固，不能代替正式学习的评分。

已删除或不再符合范围的待练卡片自动跳过，临时读取错误可重试；跳过数量在结束页单独显示。退出或重启后可继续本轮，随机顺序与选项排列不会因重新进入而改变。完整备份包含练习进度。

## 手机验收

覆盖安装新 APK 后保留已有牌组，无需重新导入。检查父牌组包含/排除子章节、退出续练、文字和图片、填空答案、最后一张结束及再练一轮；练习前后对比首页和日历，应不增加正式学习记录。测试自动覆盖 1220×2712 / DPR 3、窄屏大字体、深色和横屏布局；仍需手机确认实际图片与触感。

安装包沿用现有测试签名和版本，供本地验证；正式公开发布所需的正式签名与多机兼容测试另行完成。不要卸载已有应用；若覆盖安装报错，先保留应用及其数据。
