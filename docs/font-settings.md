# 应用内字号设置

日期：2026-11-19。开发版本：1.1.3+6。

- 入口「我的 → 字体大小」，界面 80–150%，卡片正文 80–200%，步长 5%。滑块调整预览，保存后全局生效，默认按钮恢复 100% 草稿再保存。
- 使用系统 TextScaler 输出乘以用户倍率，保留系统非线性字体缩放。100% 沿用系统。通过 FontScaleScope 保存原始系统 scaler，避免界面和阅读倍率重复相乘。
- CardContent 统一应用阅读字号，覆盖基础卡／填空、单选／多选选项、答案、解析、背卡和预览。按钮、标签、菜单等采用界面字号。图片不随字号设置放大。
- FontSettings 以单条 JSON 写入既有 app_settings 的 fontSettings，保存为原子替换，包含在现有完整备份中；不改卡片内容、排程或数据库版本。缺失、损坏或越界设置回退 100%，不妨碍访问牌组。
- 保存失败保留草稿，可重试；退出设置页放弃未保存调整。保持现有主题、东方题签和操作反馈，不新增字体文件或联网依赖。

验证和安装包信息见 `docs/releases/2026-11-19-font-settings.md`。
