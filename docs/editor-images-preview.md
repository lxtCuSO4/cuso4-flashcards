# 编辑器图片与卡片预览

入口：牌组详情 → 新建卡片，或打开已有卡片 → 编辑。

## 使用

1. 将光标移到正面／背面（填空卡为原文／补充说明）的位置，点击对应「插入图片」，选择手机本地图片。选中的文字会被图片标记替换；取消选择不改变内容。
2. 编辑区显示 `<img src="media:…">` 标记。点击「预览卡片」可查看实际排版与图片，再点击「显示答案」。返回后继续编辑，内容不会丢失。
3. 填空卡预览可选择各个填空编号。切换编号会隐藏答案；没有有效填空时会提示返回修改。
4. 点击「保存卡片」才正式保存。未保存时离开会询问是否放弃；选择、载入图片或保存期间会锁定操作，避免重复保存或中途退出。

## 图片与数据

- 支持 PNG、JPEG（JPG）、GIF、WebP，按实际编码检查并验证可解码性，保留原图，不压缩转码。其他格式先转换后插入。
- 单张最多 10 MiB、1600 万像素；本次编辑选入的不同图片合计最多 30 MiB，达到上限请先保存并重新编辑。删除标记不会立即丢弃内存草稿，以便编辑撤销；保存只写入仍在笔记中引用的图片。
- 相同图片使用同一个内容哈希，同一笔记重复引用只计算一次。使用已有媒体引用与清理规则，兼容现有本地备份／恢复。选择的原文件不会被修改或删除。
- 草稿图片仅在内存中预览。放弃编辑不产生正式媒体记录或文件；应用被系统关闭时，未保存草稿会丢失。
- 保存用临时文件写完后更名，协调媒体记录与笔记事务；失败时回滚新文件和记录，保留编辑内容及原有共享图片。意外终止可能留下不被笔记引用的完整哈希文件或临时目录，不影响已保存内容；存储管理界面仍属后续范围。
- 修改已有卡片保留排程及来源等未编辑字段；移除填空编号仍需确认。预览不创建卡片、不记录评分、不改变 FSRS、额度或统计。

这仍是文本／HTML 标记编辑器，不是所见即所得富文本编辑器。预览复用现有安全渲染，忽略脚本、CSS、远程资源和任意自定义模板。本轮未加入快捷填空、音频编辑或跨牌组搜索。
