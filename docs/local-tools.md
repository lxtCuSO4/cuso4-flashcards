# 搜索、批量管理、学习提醒与存储管理

## 手机入口

- 牌组页右上角搜索图标进入「搜索与批量管理」，默认跨全部牌组搜索。指定牌组的卡片列表右上角管理图标进入相同页面，默认限定该牌组，可切换范围／是否包含子章节。
- 搜索正面、答案、来源等已存字段，叠加牌组、基础／填空类型、单个标签、仅收藏笔记。显示完整章节路径，支持预览和编辑，每页 30 条。当前采用存储字段的字面子串匹配；跨 HTML 标签拆开的词句可能无法直接匹配，尚无分词／全文索引。
- 勾选或全选本页后，批量移动、添加标签、移除标签、删除。多标签用空格／逗号分隔。单位是笔记，影响该笔记生成的全部卡片；不会隐含选择其他分页，换页／改筛选／改搜索会清空选择。界面一次最多本页 30 条，仓储额外限制单批 500 条。
- 移动和标签修改保留 FSRS、到期时间和既有学习记录；删除有确认，删除笔记、全部生成卡片及对应学习记录／收藏。失败整批回滚。事务提交期间禁止重复提交和离开；仅在真正执行时显示进度。
- 「我的 → 学习提醒」默认关闭、默认 20:00。可选择每日时间，启用时请求通知权限，发送测试通知或打开系统通知设置。Android 8–12 使用通知渠道／系统开关，Android 13+ 另外使用运行时权限。
- 提醒由 Android 本机保存和调度，无需服务器；重启、改时间／时区、更新应用后重排。使用非精确 AlarmManager，系统省电／后台限制可能延后，强行停止后需重新打开应用。点击通知打开应用；关闭提醒会取消未来闹钟和当前通知。这是本机偏好，不随牌组备份迁移。
- 「我的 → 存储管理」显示数据库／日志及哈希媒体占用、可清理媒体、缺失／大小异常的引用。确认清理时重新扫描实际笔记引用，保护共享图片和新增加的引用；只处理私有媒体目录内无引用的哈希普通文件及匹配元数据。未知文件、符号链接、目录、备份和导入暂存文件均不删除；异常引用只报告，不自动改卡片。
- 导入页面现支持旧版和新版 Zstd 压缩 .apkg，标准基础卡／填空卡与来源、图片仍按既有规则转换，排程全部重新开始。格式和校验范围见 [modern-apkg-format.md](modern-apkg-format.md)。

## 本轮验证

集中运行搜索／批量、提醒、存储、全部导入相关、共享媒体／编辑图片、备份服务、牌组仓储、章节界面和应用导航共 82 项测试通过，静态分析无问题。关键新增检查包括笔记分页与组合筛选、SQL 字面输入、批量回滚／排程保留、通知拒绝／保存失败、清理前引用变化／过期计数、现代压缩媒体校验／截断／超限／恶意清单，以及真实旧版操作系统牌组（520 笔记／670 张卡）。

界面检查覆盖 1220×2712／DPR3（约 407×904 逻辑像素）、320dp 窄屏、1.8 倍字体和深色主题。Android Kotlin 和 release lint 随最终离线 APK 构建通过；没有进行实际 Android 安装、提醒送达／开机恢复、真实新版 Anki 导出包或多机型测试。

建议手机验收：

1. 覆盖安装后先确认原牌组、图片和学习进度仍在；用一个旧笔记分别搜索正面／答案，切换章节范围与筛选，预览和编辑。
2. 用几条临时笔记验证移动、标签、删除取消／确认以及分页清空选择；移动原有已学卡后确认进度保留。
3. 开启提醒并发送测试通知，点击通知回到应用；把时间设在几分钟后，息屏等待，再检查关闭后取消、重启后恢复。拒绝权限时应保持原设置并提示。
4. 存储页刷新统计，核对仍在使用的共享图片在清理后正常显示。该页不自动修复缺失的媒体。
5. 用 Anki 正常导出的新版压缩包验证章节、基础卡／填空卡、来源、图片和新卡状态；复杂自定义模板仍可能跳过并进入报告。
