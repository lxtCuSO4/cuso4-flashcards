# 月相外观、刷题统计与本轮答题卡

版本：1.1.6+9；日期：2026-11-20。

## 页面与操作

首页、牌组、记录、“我的”及工具表单使用纸色、墨青、淡玉与旧金的外部主题，月相序列为固定识别元素。首页与记录页以月盘搭配真实学习数据，牌组目录采用书脊色条，“我的”按学习、外观触觉、设备数据与反馈分组。原 logo、东方题签、仓库配图与所有原有操作保留。

学习、题目、解析、背卡和卡片预览继续使用原阅读主题与布局。外部主题通过 LunarSurface / LunarScope 局部应用，避免更换全局 AppTheme。主视觉使用 CustomPainter，无新增图片、字体或依赖。浅深色与系统字号均沿用用户设置。

题目页与解析页右上角网格按钮打开本轮答题卡；完成页同样提供入口。题号显示答对、答错、已看答案、跳过或未答，并标出当前题与收藏。可筛选并跳转，恢复原选择及选项排列；已提交题回看保持锁定，不重复判分或增加错题次数。上一题与返回本轮结果位于题目页更多菜单。

跳到末题不会使前面未完成题被隐式结束。末题推进时查找尚未结算的题目；全部提交、看过答案并离开或明确跳过后，才显示本轮结果。新轮次仍按当前范围重新取全部有效卡片，旧轮次答题卡被替换，真实历史提交保留。

## 独立统计

记录页区分记忆学习与选择题练习，提供 7／30／90 天及全部的提交题次、正确率、对错数量、前台用时、刷题月历和日期详情。详情保留提交时的题干摘要、来源牌组、牌组／收藏／错题入口和提交时间。

只有真实提交产生一条作答事件，题次是提交次数而非去重卡片数。题目内容修改后重新作答可产生新事件，新开一轮可再次作答；同一题版本重复提交、解析与回看不新增事件。提交时的历史摘要和结果不会随之后编辑或删除题目改写。仅浏览基础卡不增加刷题数据。

前台计时在后台、编辑、解析及答题卡期间暂停，切题与正常离开会保存累计值，提交时写入统计。崩溃或进程强制终止可能损失最后一次保存后的少量时间。学习日沿用既有时区设置；统计与 FSRS 日志、额度、到期时间隔离。

## 数据与升级

SQLite schema 与备份格式均保持 2，无数据库迁移需求。新增记录保存在现有 AppSettings 内：

| 命名空间 | 用途 |
| --- | --- |
| `practice:v1:<scope>:queue/cursor` | 当前范围的题序、全局计数和当前位置，内部队列／游标写入版本 2 |
| `practice:card:<roundId>:<cardId>` | 当前轮次逐题选项、答案状态、内容指纹、前台时长与版本计数 |
| `practice:attempt:<UTC日期>:<roundId>:<cardId>:<generation>` | 真实提交时的不可重复事件，按时间范围查询统计 |

内容指纹采用 SHA256，避免在每题快照中重复保存完整 HTML。判分、错题变动、作答事件与游标更新同一事务提交。新轮次删除对应旧轮的逐题快照以控制存储增长，保留历史事件；其他范围的轮次不受影响。全局设置订阅排除 practice 命名空间，避免计时／选项保存带动主题刷新。

1.1.5 及以前只保存当前题状态与总计数。升级保留原轮次进度与当前有效作答；之前未知题标为“已练习（旧版无答案记录）”，允许回看，但不伪造选项、日期或真实提交。需要重新作答时新开一轮。完整备份自动包含新记录，旧备份中没有新记录时正常从空白历史开始。

## 验证范围

数据检查覆盖真实提交去重、查看解析不计分、逐题草稿恢复、跳到末题的未答处理、旧游标兼容、改题重置计数、新轮次快照回收、学习日边界、范围统计和备份保留。

实际 Flutter 交互检查覆盖题目／解析／答题卡／结果之间的跳转、错误次数不重复累加、刷题记录日期详情，以及 1220×2712、浅深色、大字号与横屏布局。主页面截图位于 `build/previews/lunar-*.png`。仅用于本地截图的 Windows 字体不加入安装包；外部顶栏明确继承主题字体，避免预览测试中出现方块。

构建与签名结果、产物校验值见本版验收记录。真实手机覆盖安装、触觉体验与长期使用仍需设备验收。PDF 制卡、编辑草稿恢复与回收站不在本批范围。
