# Lunar Memory 1.0.0 开发预览版

发布日期：2026-10-16。标签：`v1.0.0-preview.20261016`。

## 下载与安装

- `lunar-memory-choice-import-arm64.apk`：适用于 Android 8.0 及以上的 ARM64 手机，大小约 22.9 MB。
- `Lunar-Memory-User-Guide.txt`：用户使用指南。

已安装旧版的用户可直接覆盖安装。包名和签名与此前提供的安装包一致，可保留原有牌组和学习进度；建议更新前先导出本地备份，不要先卸载应用或清除应用数据。

本版沿用开发测试签名，真机兼容验收仍在进行中。

## 主要更新

- 支持在应用内创建、编辑和练习单选／多选题，提供选项图片、解析、可选乱序及作答结果提示。
- 导入 `.apkg` 时识别题干、连续 A–H 选项和明确答案，自动转换为对应选择题；无法确定时保留为基础卡。用户提供的数据库模拟卷已验证为 67 道单选、17 道多选。
- 已导入的基础卡可在「牌组 → 识别已导入选择题」中扫描并确认转换，保留学习进度、复习记录、收藏、标签及媒体。
- 「我的」页新增问题反馈表单，邮件收件人为 `lixingtong035@163.com`；通过手机邮件应用确认发送，未安装邮件应用时可复制反馈内容。
- 「我的」页新增 GitHub 仓库入口及本地配图，保留按压和触觉反馈。
- 更新用户使用指南，统一为正式、清晰的表述。

导入、学习、练习、统计及备份继续支持离线使用。应用当前不自动检查更新；完全离线时无法获知新版本，可联网访问本仓库 Release 页面手动下载更新。PDF 转卡不包含在本次发布中。
