# Lunar Memory 1.1.6 本地验收

日期：2026-11-20；版本：1.1.6+9。

## 交付内容

- 非学习页面接入纸色／墨青月相主题，首页和记录页月盘、牌组书脊、“我的”分组以及工具表单统一；保留 logo、东方题签、仓库配图、触觉与字号设置
- 学习、题目、解析、背卡与内容预览保持原阅读主题，新增答题卡控制入口
- 独立选择题统计：7／30／90 天及全部、题次、正确率、对错数量、前台用时、刷题日历与日期详情
- 本轮答题卡：逐题草稿与答案保存、状态与收藏标记、筛选跳转、上一题、完成后回看及返回结果
- 回看与解析不重复判分、不增加历史事件或错题次数；末题推进不隐式跳过未完成题
- 编辑题目后修正本轮计数；新轮次清理被替换的旧答题卡快照，保留真实提交历史
- 正常退出、后台、编辑与切题保存作答用时；解析和答题卡期间暂停计时
- 旧版进度与总计保留，缺失历史答案明确标注；SQLite schema 2 与备份格式 2 保持不变

详细说明见 `docs/lunar-records-answer-sheet.md`。
