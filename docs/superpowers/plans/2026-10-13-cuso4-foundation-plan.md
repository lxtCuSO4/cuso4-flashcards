# CuSO₄闪卡 Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Create the Android Flutter project, responsive visual system, strong tactile feedback, local database, and tested deck/card editing foundation.

**Architecture:** A feature-first Flutter project uses Riverpod for dependency injection and Drift for typed SQLite access. Domain interfaces do not import Flutter, so parsing, persistence, and scheduling logic are independently testable.

**Tech Stack:** Flutter stable, Dart, flutter_riverpod, go_router, Drift, sqlite3_flutter_libs, path_provider, Material 3.
