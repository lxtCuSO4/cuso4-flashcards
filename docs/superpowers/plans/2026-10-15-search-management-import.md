# 搜索、批量管理、提醒、存储与新版导入实施计划

**Goal:** 完成用户指定的五项本地功能，并在一份可覆盖安装的 ARM64 APK 中交付。

**Architecture:** 维持 schema 1 和既有安全渲染、媒体引用、备份格式。搜索分页查询笔记并复用编辑／预览；批量操作事务处理明确的笔记 ID；提醒用 Android 原生通道及持久化每日闹钟；存储清理在锁定事务中复查引用；现代 apkg 复用 archive 内置 Zstd，读取 protobuf 清单及规范化集合元数据。

**Tech Stack:** Flutter、Riverpod、Drift／SQLite、现有 archive／crypto，Android Kotlin。当前会话顺序实施，遵循用户预算限制，不派发代理，阶段集中验证，最终只构建一次 APK。

## 1. 跨牌组搜索

- [x] 新建 SearchRepository／SearchPage，牌组页设置“搜索与批量管理”入口。
- [x] 内容字面子串搜索、精确标签、卡片类型、仅收藏筛选；全部牌组或指定牌组及子章节。显示完整章节路径，每页 30 条，稳定按 ID 排序；筛选／页码变化清空选中范围。
- [x] 显示笔记摘要、卡片数，支持预览和编辑；查询加载／失败／空状态，300ms 防抖，销毁取消计时器。

## 2. 批量管理

- [x] 在搜索页多选、本页全选；明确影响选中笔记生成的全部卡片，单批最多 500 条。不隐含选中其他分页。
- [x] 批量移动、添加标签、移除标签、删除。仓储检查全部 ID 和目标牌组，参数校验与事务回滚；移动／标签不修改 FSRS，删除在应用内确认后执行并复用媒体计数规则。

## 3. 本地学习提醒

- [x] “我的 → 学习提醒”，默认关闭，默认时间 20:00；用户启用时请求通知权限，显示系统允许状态、设置入口与测试通知。
- [x] Android 原生 AlarmManager 每次安排下一天的非精确提醒；重启／时区／时间变化／应用更新后重排。点击通知打开应用，关闭取消闹钟和既有通知。无网络、无精确闹钟特殊权限。

## 4. 存储管理

- [x] “我的 → 存储管理”，显示数据库／媒体实际占用、可清理数量和大小、缺失引用数量；异常／未知路径不纳入删除。
- [x] 应用内确认后复查全部笔记引用，仅清理私有媒体目录内无引用的哈希普通文件及对应媒体行，保护共享图片，排除链接、目录、备份和导入中暂存文件。

## 5. 新版压缩 apkg

- [x] 研究官方 PackageMetadata／MediaEntries 及现代数据库 notetypes／fields／decks 格式，记录来源；保留旧版回归。
- [x] 校验 meta 版本，使用受大小限制的流式 Zstd 解码 collection.anki21b／media／媒体文件；验证清单路径、大小、SHA1、重复项和损坏输入，整包解压量不超过既有上限。
- [x] 现代集合按规范化表读取卡型、字段和完整章节名；继续仅转换基础／填空及 Source，所有卡片从新卡开始。
