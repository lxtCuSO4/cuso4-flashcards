# 学习设置

进入“我的 → 学习设置”，修改后点击“保存学习设置”。设置和学习数据一起保存在本机，无需联网；现有 `.cuso4backup` 备份会包含这些设置。

| 设置 | 默认值 | 范围 |
| --- | --- | --- |
| 每日新卡数 | 20 张 | 0–9999 的整数 |
| 每日复习上限 | 200 张 | 0–99999 的整数 |
| FSRS 期望保持率 | 90% | 70–99 的整数百分比 |

期望保持率在“FSRS 进阶设置”内。更高的目标通常意味着更频繁的复习，建议先使用 90%。此目标用于算法计算，不是对记忆结果的保证。

## 何时生效

保存后，下次进入学习时生效。该轮的队列、四项间隔预览和评分使用同一份设置，重新载入及撤销不会在中途改用另一个保持率。

修改不会重置卡片、改写复习日志或立即重新计算已有卡片的到期日。新保持率在后续评分时使用；学习中的分钟级步骤仍沿用既有 FSRS 学习步骤。

## 每日额度

- 每张卡片按所属牌组独立计数。父牌组与各子章节分别享有额度；选中父牌组学习会包含其子章节，但不是整个父牌组树共用一个额度。
- 同一天按卡片数量计算，学习中／重学中卡片不受两项上限限制。设置为 0 暂停对应的新卡或到期复习卡，不删除卡片。
- 调整额度会考虑今天已完成的数量，不会额外赠送一批。撤销评分会归还该次消耗的额度。
- 在首次学习时记录的时区的零点换日，之后改变设备时区不会重新获得当日额度。本轮未提供修改学习日时区的功能。
- 设置读取失败时不使用默认值继续学习，可重试；损坏的设置不会被静默覆盖。保存失败保留表单输入，三项设置一次写入，不产生部分更新。

## 手机最小验收（尚待用户操作）

覆盖安装新 APK，保留旧数据。进入学习设置，把新卡数改为 1，保存并重新进入一个有未学卡片的牌组。学完一张后不再出现其他新卡；学习中卡片按时出现，撤销可恢复上一张卡。重新打开设置应保留数值。

可把保持率改为 95%，重新进入学习，检查四项评分及撤销仍正常。已有卡片不因保存设置立即改变到期日；评分后的间隔才使用新目标。按个人习惯恢复每日额度即可。

此版本依旧为 ARM64、Android 8.0 及以上的本地测试包，尚未完成广泛机型兼容和正式发布签名。
