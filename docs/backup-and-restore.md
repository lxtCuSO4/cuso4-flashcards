# 本地备份与恢复

入口：我的 → 备份与恢复。无需账号或服务器。

## 导出

1. 点击“导出本地备份”，等待一致性快照、打包和校验完成。
2. 在安卓系统文件界面选择手机内的保存文件夹。
3. 出现“备份已保存”后，确认文件名以 `.cuso4backup` 结尾，并妥善保管。

备份包含 SQLite 数据库、所有实际引用的媒体、牌组层级、基础卡／填空卡、标签、收藏、FSRS 状态、复习日志及全部设置。没有被卡片引用的媒体不打包。媒体缺失或校验失败会拒绝生成不完整备份。上次成功导出的时间和文件大小显示在页面中。

备份不加密，能够读取该文件的人可能读取卡片内容。导出到应用外的目录，避免卸载时一并丢失。`.apkg` 仍只用于导入 Anki 牌组，不能用作本应用的完整进度备份，也不能将 `.cuso4backup` 当作 Anki 牌组。

## 恢复

1. 先导出一份当前数据的备份。不要通过卸载应用测试恢复。
2. 点击“选择备份并恢复”，选取 `.cuso4backup` 文件。
3. 应用检查版本、空间、ZIP 路径和大小、文件校验、数据库结构和完整性、媒体与卡片引用。
4. 阅读风险确认后，点击“确认恢复”。这是整体替换，不是追加或合并。
5. 等待恢复完成，应用回到“我的”。检查卡片数量、图片、学习进度、收藏和外观设置。

恢复使用本应用保留的原始排程，不会像 `.apkg` 导入那样重新开始学习。替换前关闭数据库并保留当前数据库与媒体；只有新数据检查通过才记录提交。失败回滚，重启时先处理未提交的恢复记录，再开放数据库。恢复记录本身损坏时停止打开数据库，并提示保留应用数据。

## 恢复前快照

恢复成功后，在相同页面点击“导出恢复前快照”，可将恢复前的数据保存为正常备份包，再自行选择该文件恢复。本机仅保留最近一次恢复前的快照；下一次成功恢复会替换旧快照。快照位于应用私有目录，会随卸载丢失，不代替手动导出到应用外的备份。

## 边界

- 当前格式版本 1、数据库版本 1；较新版备份要求更新应用。
- 归档解压总量上限为 2 GiB，最多 50,000 个文件，清单最多 8 MiB。
- 开始前检查应用所在磁盘的可用空间，并预留 16 MiB；系统保存界面的目标卷或提供方空间另由实际写入处理。
- 打包和校验在后台 isolate 进行；取消需等待当前步骤结束。正式切换时不能取消，且请勿强行关闭应用。
- 安卓导出使用系统创建文档界面和 128 KiB 文件流，不申请宽泛存储权限。
- 普通写入失败会尝试删除目标残缺文件，但部分系统文档提供方可能不允许删除；强制结束导出也可能留下一份不完整外部文件。恢复会拒绝校验不通过的文件，请重新导出。
- 导入进行中禁止备份／恢复，处理中禁止重复触发和返回。
- 本轮自动化验证不代替真机文件提供方、空间耗尽、强制终止和跨设备恢复验收。

## 真机最小验收

覆盖安装更新 APK，不卸载现有应用。导出备份 → 新建一张临时卡片 → 恢复刚导出的备份 → 确认临时卡片消失、原牌组／图片／进度／收藏正常 → 导出恢复前快照 → 确认文件可选择。恢复测试前保留一份应用外备份。
