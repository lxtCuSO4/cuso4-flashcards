# 独立选择题解析页

日期：2026-11-19。开发版本：1.1.2+5。

- 适用于组内顺序／随机、错题专项、收藏专项和混合自由练习里的单选题、多选题。
- 提交成功后才进入解析页；解析页显示判分、当前选项字母对应的答案、正确选项和原解析，支持本地图片。保存失败留在题目页重试。
- 题目页隐藏长解析，保留简要判分和原有下一张按钮，新增查看解析。未提交查看时视为未作答并锁定选项；不更新错题。
- 解析页底部固定返回题目、下一题（最后一题完成本轮）；顶部返回箭头和系统返回也保留当前题。返回或重复查看不重判、不打乱原选项。
- 解析页通过临时导航返回是否推进，原 PracticePage 统一推进一次。作答快照为不可变数据；解析页不创建新的学习队列，不调用判分仓储。
- 修正慢速保存期间父组件刷新可能将成功揭示回调替换为禁用空回调的问题；提交开始时保留事件回调，成功后正常锁定题目并打开解析。失败仍留在题目重试。
- 只读预览、背卡、基础卡、填空卡保留原显示方式。无数据库升级，无新依赖，无服务器功能。
- 使用现有主题、东方题签、图片渲染和按键反馈；固定底栏遵循安全区。UI 技能数据库没有匹配的 SafeArea 条目，布局采用该技能通用安全区规范和项目现有 Flutter 组件。

验证及安装包信息见 `docs/releases/2026-11-19-choice-explanation.md`。
