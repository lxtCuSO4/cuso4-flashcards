# 章节折叠与收藏列表增量设计

日期：2026-10-15。章节交互已由用户确认“默认收起”；收藏列表沿用既有产品规格与本轮继续开发授权。

- 多级牌组首次默认收起，点击左侧箭头展开/收起；点击牌组名仍进入原有卡片页。叶子牌组没有折叠按钮。
- 每个牌组的展开状态独立保存到 app_settings，跨路由和重启保留。折叠父级不清空后代的选择；不修改牌组、笔记、排程或日志。保存期间防重复点击，失败显示错误，不伪报已保存。
- 沿用主题与 Material 图标，箭头提供明确状态、至少 48dp 点击区、触觉与短按压/旋转反馈；减少动画时不旋转动画。
- 收藏列表从“记录”进入，按最近收藏时间及卡片 ID 稳定排序，每页最多 30 张；支持原生安全卡面预览、显示答案和取消收藏，取消后可撤销。
- 收藏以卡片为单位；同一 Cloze 笔记的不同编号分别显示。预览不调用评分或学习队列接口，不写入 FSRS、复习日志或每日额度。
- 本轮不实现收藏筛选/专项正式评分、统计日历、通知、备份，不新增依赖或修改数据库版本；保留后续开发安排。
- 在工程内运行相关测试、一次静态分析、一次离线 ARM64 release 构建；保留上一个可用 APK，包名和签名不变，不上传 GitHub。
